# Task E (bonus) — Шлях 1: перевірка крос-tool переносності

**Порівнювані інструменти:** крос-tool конвенція `.agents/skills/` проти
рідного для Claude Code шляху виявлення `.claude/skills/` — обидва в цьому
репозиторії.
**Промпт (однаковий в обох):** запит на widget `alert` з
`materials/ab-task.md` (той самий промпт, що й у Task D).
**Скіл, що тестується:** `creating-widget`, скопійований **побайтово** —
перевірено порівнянням файлів, яке не показало жодних відмінностей між двома
копіями.

Цей шлях обрано не заради зручності: до нього змусив Task D. Перший прогін A/B
дав ідентичний результат зі скілом і без нього, і я не міг визначити, що це
означає — «скіл зайвий» чи «скіл узагалі не завантажився». Саме підтвердження
виявлення скіла в другому розташуванні це й розв'язало.

| | Лише `.agents/skills/` | Додано дзеркало `.claude/skills/` |
|---|---|---|
| Скіл виявлено/завантажено? | **Не спостережувано** — агент жодного разу його не назвав | **Так** — з'явився у списку доступних скілів, і агент сказав, що діє «following the `creating-widget` golden path» |
| Дотримано golden path? | Так — правильне розташування, `register()`, колокований тест, імпорт у barrel-файлі | Так — побайтово ідентичний результат |
| Глибина перевірки | лише `npm test` | `npm test` + `npm run typecheck` + перевірка в рантаймі через `listWidgets()` / `create()` |
| Розбіжності | Результат був правильний, але приписати його скілу було неможливо | Немає — той самий вміст файлів плюс явна згадка скіла |

**Вміст файлу не потребував жодної адаптації.** Frontmatter (`name` +
`description`), тіло у Markdown і відносні посилання на `references/` та
`scripts/` спрацювали без змін. Єдине, що довелося змінити, — **де лежить
тека**; звичайне копіювання, без правок:

```text
.agents/skills/creating-widget/SKILL.md   ← крос-tool конвенція
.claude/skills/creating-widget/SKILL.md   ← рідний шлях Claude Code
```

**Висновок:** **формат** `SKILL.md` справді переносний — той самий файл
підхопився без модифікацій. А от що НЕ переносне, так це **шлях виявлення**:
`.agents/skills/` — це конвенція, яку сьогодні читає не кожен інструмент, а
скіл у шляху, який ваш інструмент ігнорує, нічим не відрізняється від
відсутності скіла взагалі. Практичний висновок: у переносності є дві половини,
і половина з форматом — легша. Варто також проєктувати скіли так, щоб агент
*повідомляв* про їх використання: без цього сигналу я не мав жодного способу
відрізнити завантажений, але зайвий скіл від незавантаженого — а саме це й
зробило мій перший результат A/B недостовірним.

> Примітка: `.gitignore` у цьому репозиторії ігнорує `.claude/*`, але має
> виняток `!.claude/skills/`, тож дзеркало комітиться свідомо — як результат
> цього шляху.
